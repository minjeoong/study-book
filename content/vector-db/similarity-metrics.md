```formula
d(A, B) = √( Σ (aᵢ − bᵢ)² ) :: 유클리드 거리, 0이면 같은 위치, 클수록 멂
cos θ = (A · B) ÷ (‖A‖ ‖B‖) :: 코사인 유사도, 방향만 비교 (−1 ~ 1)
‖A‖ = ‖B‖ = 1 이면 cos θ = A · B :: 정규화 벡터에서는 내적 = 코사인 (DOT)
```

```compare
유클리드 거리 (직선 자) | 코사인 유사도 (화살표 각도)
보는 것 | 두 점 사이 실제 공간 거리 | 두 화살표가 가리키는 방향
값 해석 | 작을수록 유사 (0이면 같은 위치) | 클수록 유사 (1이면 같은 방향)
길이 영향 | 매우 민감 (긴 글·짧은 글 비교 시 왜곡) | 영향 없음 (주제·문맥만 비교)
주 사용처 | 얼굴 인식, 센서값, 이미지 특징점처럼 크기가 중요 | 텍스트 검색, 문서 Q&A, RAG 챗봇
```

> [!warn] 길이의 함정
> "영화가 재미있었다."와 "이 영화는 정말 너무너무 재미있고 연기도 훌륭해서 ... 즐겼다."는 둘 다 영화 칭찬이지만, 긴 문장의 벡터가 원점에서 훨씬 멀리 찍혀 유클리드 거리로는 "다른 내용"으로 오판됨.
