    a: "TF-IDF는 이 문서에 자주 나오면서 다른 문서엔 드문 단어에 가중치를 줘서 조사·불용어 문제는 풀지만, 여전히 글자 모양이 일치하는지만 본다. 그래서 '스마트폰 고장'과 '아이폰 액정 파손'은 겹치는 단어가 0개라 유사도 0점이 되고, 어순도 몰라 '고객이 상담원에게 화를 냈다'와 그 반대 문장을 구분하지 못한다. 사전 크기만큼 거대한 희소 벡터라 메모리 낭비도 크다."

```flow
원-핫 인코딩 :: 단어마다 방 번호, 자기 칸만 1 — 단어 간 관계 없음, 10만 칸 중 1칸만 1
Bag of Words :: 문장 속 단어 등장 횟수 — 어순 무시, 조사·불용어가 최고 점수
TF-IDF :: 자주(TF) × 희귀(IDF) 가중치 — 핵심 키워드는 잡지만 여전히 글자 일치만
어휘 불일치 :: 동의어·상하위 개념·오타·신조어에서 검색 실패
Dense Embedding :: 뜻이 같으면 가까운 좌표로 — Vector DB의 출발점
```

```compare
정형 데이터 | 비정형 데이터
형태 | 행·열이 정해진 테이블 (나이, 가격, 회원 번호) | 정해진 칸이 없음 (이메일, 통화 녹음, 사진)
컴퓨터 처리 | 숫자 대소 비교로 ms 단위 필터·정렬 | 유니코드 바이트, RGB 숫자 배열로만 보임
검색 | WHERE 가격 < 1000000 처럼 정확 | 키워드가 조금만 달라도 놓침
비중 | 약 20% | 80% 이상 (실질적 지식과 인사이트)
```

> [!warn] 같은 뜻, 다른 글자
> "휴대폰 액정이 깨졌어요"로 검색 → 매뉴얼 제목은 "스마트폰 디스플레이 파손 수리 가이드". 사람은 1초 만에 같은 뜻임을 알지만 글자를 비교하는 검색은 결과 0건. "월급↔급여", "과일→사과", "배터리↔밧데리"도 같은 문제.
