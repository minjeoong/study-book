qa:
  - q: "메타 프롬프팅이란?"
    a: "AI에게 직접 답을 시키는 것이 아니라 더 좋은 사고 방식, 문제 해결 방식, 프롬프트를 스스로 구성하게 하는 기법이다. 예를 들어 '너는 반도체 선행연구를 위한 AI 프롬프트 엔지니어다. HBM 논문 분석용 전문가 수준 프롬프트를 생성하라'고 하고 기술 차별점, 양산 난이도, 열 문제, 패키징 bottleneck, 경쟁사 비교를 포함하라고 지정한다. AI에게 답을 묻는 게 아니라 사용자의 사고 프레임워크를 만들게 하는 기술이다."
  - q: "프롬프트를 Markdown으로 쓰면 좋은 이유는?"
    a: "좋은 프롬프트는 구조화된 프롬프트이고, Markdown은 #, -, ** 같은 간단한 기호로 제목·목록·강조를 의미적으로 구분해 준다. LLM이 학습 과정에서 Markdown 문서를 매우 많이 접해 Markdown 구조의 프롬프트를 더 안정적으로 해석하는 경향이 있다. 또 공개된 고품질 프롬프트 대부분이 Markdown이라 좋은 패턴을 가져다 쓰기 쉽다."

```flow
Role 부여 :: 너는 반도체 선행연구를 위한 AI 프롬프트 엔지니어다
목표 지정 :: HBM 관련 논문 분석용 전문가 수준 프롬프트를 생성하라
사고 구조·평가 기준 :: 기술 차별점, 양산 난이도, 열 문제, 패키징 bottleneck, 경쟁사 비교
출력 구조 정의 :: 기본형(단일 논문 분석), 실전형(경영진 보고용 요약 변환) 등 용도별 프롬프트
```

| Markdown 문법 | 프롬프트에서의 용도 |
| --- | --- |
| `#` / `##` / `###` | 섹션·제목 계층 (역할, 지시, 출력 구조 구분) |
| `**굵게**`, `*기울임*` | 반드시 지킬 조건 강조 |
| `- 항목`, `1. 항목` | 조건 나열, 순서가 있는 절차 |
| 표 (헤더 + `---` 구분 행) | 비교 항목, 출력 표 형식 지정 |
| `---` | 내용 구분선 (예시와 본문 분리) |

> [!tip] 실습 적용
> System Prompt에 `# 반려동물 헬스케어 시장 분석 보고서` → `## 1. 시장 개요` → `- 시장 현황`처럼 출력 구조를 Markdown으로 박아 두면 매번 같은 목차의 보고서가 나온다.
