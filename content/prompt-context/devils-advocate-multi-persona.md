qa:
  - q: "Devil's Advocate Prompting이란?"
    a: "실행 전에 잠재적 실패를 먼저 예측하고 대안을 준비하게 하는 방식으로, 심리학의 Pre-mortem에서 영감을 받았다. '뭐가 잘못될 수 있어?'라고 물으면 조심스럽고 두루뭉술한 답이 나오지만, '이미 실패했어, 왜인지 말해봐'라고 하면 훨씬 구체적이고 솔직한 이유가 나온다. 예를 들어 '이 제안서가 투자심의위원회에서 부결됐다고 가정하고, 부결 이유 5가지와 보완책을 제시해'라고 쓴다."
  - q: "Multi-Persona 프롬프팅의 장점은?"
    a: "하나의 AI에게 서로 다른 입장의 역할을 동시에 부여해 충돌과 반박을 일으키고, 의사결정의 사각지대를 찾는다. ROI와 재무 리스크를 보는 CFO, 현업 적용과 운영 효율을 보는 COO를 토론시키면 단일 관점에서 놓친 반대 논리가 드러난다. Multi-Persona 기반 debate는 수학적 추론, 팩트체킹, 의사결정, 코드 분석에서 성능 향상이 검증됐다."

```compare
Devil's Advocate | Multi-Persona
핵심 | 실패를 가정하고 반론 생성 | 여러 역할이 서로 토론·반박
영감 | 심리학의 Pre-mortem | AI 레드팀, 주장·기술 검증
프롬프트 | 이 제안서가 부결됐다고 가정하라 | 너는 지금부터 CFO와 COO다, 서로 반박하라
결과 예시 | 부결 이유 5가지(ROI 근거 부재 등) + 재승인 전략 | 조건부 보류 + 60일 내 재무·운영 보완 조건
```

```
너는 지금부터 두 명의 임원이야.
[CFO] 투자 대비 수익(ROI)과 재무 리스크를 중시. 투자 회수 기간과 비용 구조 검토
[COO] 실제 현업 적용 가능성과 운영 효율을 중시. 조직 변화와 실행 가능성 검토

아래 투자안을 검토하라.
각자 찬성 또는 반대 의견을 제시하고, 다른 임원의 주장에 반박하라.
토론이 끝난 후 최종 투자 여부와 승인 조건을 정리하라.

[투자안] 과제명: 고객 상담 AI Agent 구축 / 기간: 6개월 / 예산: 10억원
```

> [!tip] 실습 적용
> 전략수립 System Prompt에 "시장 진출 전략이 실패했다고 가정하세요. 왜 실패했을지 분석하고, 실패 원인을 바탕으로 더 구체적인 보고서를 작성하세요"를 넣자 결과에 '실패 가능성 분석' 섹션이 먼저 생겼다.
