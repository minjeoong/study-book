qa:
  - q: 결측치는 어떻게 처리하나요?
    a: "먼저 결측이 어디에 얼마나 있는지, 왜 생겼는지 확인합니다. 비율이 작으면 해당 행을 지우고, 한 변수의 절반 이상이 비면 그 열을 지우는 것을 검토합니다. 남기는 경우 범주형은 최빈값이나 'Missing' 범주, 수치형은 평균이나 이상치에 강한 중앙값, 또는 그룹별 조건부 대체나 회귀·KNN 같은 모델 예측으로 채웁니다."
  - q: 무작위 결측과 비무작위 결측은 어떻게 다른가요?
    a: "무작위 결측(엄밀히는 MCAR)은 미입력이나 시스템 오류처럼 결측이 다른 변수나 값 자체와 연관이 없는 경우입니다. 비무작위 결측(MNAR)은 결측 여부 자체가 값과 관련된 경우로, 체중이 많이 나가는 사람이 체중을 공개하지 않는 것이 예입니다. 비무작위 결측을 평균으로 채우면 편향이 생기므로 결측 여부 플래그를 따로 만들거나 'Missing' 범주로 두는 것이 낫습니다."
  - q: 결측이 있는 행을 모두 지우면 왜 문제가 되나요?
    a: "데이터가 크게 줄고, 결측이 특정 클래스에 몰려 있으면 레이블 불균형까지 생길 수 있습니다. 또 결측이 비무작위라면 남은 데이터가 모집단을 대표하지 못해 편향된 모델이 됩니다. 시계열은 구간마다 평균·분산이 달라(비정상성) 전체 평균 대체도 위험해 직전 값, 이동평균, 보간법을 씁니다."

```flow
확인 :: isnull().sum()·mean(), missingno로 패턴, 결측의 비즈니스 의미
제거 (Deletion) :: 행 결측 10% 이하 → 행 삭제, 열 결측 50% 이상 → 열 삭제 검토
대체 (Imputation) :: 최빈값(범주), 평균·중앙값(수치), 조건부 대체(그룹별 값)
예측 (Prediction) :: 결측 없는 데이터로 회귀·KNN 모델을 만들어 결측값 예측
```

| 상황 | 방법 | 주의 |
| --- | --- | --- |
| 수치형, 치우친 분포 | 중앙값 | 평균은 이상치에 끌려감 |
| 범주형 | 최빈값 또는 'Missing' 범주 | 최빈값 쏠림 심화 |
| 그룹별로 값이 다름 | 조건부 대체 (지역별 중앙값) | 그룹 표본 수 확인 |
| 시계열 | 직전 값, 직전 n일 이동평균·중앙값, 선형·스플라인 보간 | Cubic Spline도 항상 최선은 아님 |
| 패턴이 있는 결측 | 회귀·KNN 예측 대체 | 생성값이 비즈니스 상식에 맞는지 |

> [!warn] 헷갈리기 쉬움
> 대체 기준(중앙값 등)은 Train에서만 계산해 Test에 그대로 적용한다. 전체 데이터로 계산하면 Test 정보가 새는 데이터 누수다. 결측값 자체가 Trend의 일부라 부정적 결과를 예측하는 설명력이 있을 수 있으니 결측 여부 플래그도 고려.
