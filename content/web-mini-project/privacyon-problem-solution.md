qa:
  - q: 이 프로젝트를 소개해 주세요.
    a: 'PRIVACY ON은 기업이 공개한 개인정보 유출 사고에서 내 정보가 실제로 포함됐는지 확인하고, 유출 항목·보상·대응 방법과 비밀번호 변경 여부까지 한곳에서 관리하는 웹 서비스입니다. 직접 유출 대상 안내를 받았을 때, 보상 안내는 앱 홈에 있는데 정작 내 유출 항목은 공지사항 > 유출 게시물 > 조회 버튼까지 들어가야 보였던 경험에서 출발했습니다. 기업 담당자, 플랫폼 관리자, 일반 사용자 세 액터로 나눠 화면 흐름, ERD, API 명세까지 설계했습니다.'
  - q: 문제를 어떻게 검증했나요?
    a: '제 경험 하나로 일반화하지 않으려고 유출 피해자 인터뷰를 했습니다. 자기 정보가 유출된 사실조차 모르던 사람, 유출 사고 뒤 불안해서 서비스를 탈퇴한 사람이 있었고, 이를 "유출 소식이 뉴스로만 파편화돼 있다", "어떤 정보가 유출됐는지 모른다", "비밀번호 변경 같은 후속 조치를 했는지 기억 못 한다"는 세 문제로 정리했습니다. 해결안도 이 세 문제에 하나씩 대응하도록 만들었습니다.'

```flow
경험 :: 유출 대상 안내를 받았지만 내 유출 항목은 4단계 메뉴 안
가설 :: 다른 사람들도 자기 유출 상태를 모르고 지나치지 않을까?
유저 인터뷰 :: "유출된 줄도 몰랐다" · "유출 사고로 탈퇴했다"
문제 3개 :: 파편화된 소식 · 유출 항목 모름 · 후속 조치 망각
해결안 :: 문제마다 기능 하나씩, 결과는 홈 화면 한곳에
```

```compare
문제 | 해결
① 유출 소식 | 뉴스로만 접해 파편화 | 공개된 사고에서 내가 실제 대상인지 확인, 결과를 홈 한곳에서 관리
② 유출 항목 | 유출돼도 무엇이 나갔는지 모름 | 사고 상세에서 유출 항목 · 발생일 · 보상 안내 · 대응 가이드를 한눈에
③ 후속 조치 | 비밀번호를 바꿨는지 기억 못 함 | 서비스별 비밀번호 변경 체크리스트로 완료 여부를 직접 기록
```
