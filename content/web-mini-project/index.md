## 한눈에 보기

```flow
문제 제기 :: 유출 안내를 받아도 내 유출 항목은 깊은 메뉴 안, 유저 인터뷰로 인지 부재·탈퇴 확인
해결안 :: PRIVACY ON — 공개된 유출 사고에서 내가 대상인지 확인하고 대응까지 한곳에서
액터 · 화면 :: 기업 담당자 · 플랫폼 관리자 · 일반 사용자, 화면 15개와 호출 API
데이터 · API :: 테이블 13개 ERD, OpenAPI 3.0 엔드포인트 32개 (태그 4개)
고려사항 :: 예외 시나리오별 상태 코드, 인증 · 통계 성능 · 알림 확장
```

설계의 중심 — 정보유출 대상 확인 (ERD 설계 포인트)

```flow
기업 제출 :: 피해 대상 이메일을 SHA-256 해시로만 전송, 원문은 받지 않음
저장 :: incident_affected_identifier.identifier_hash (char 64)
관리자 승인 :: 해시가 일치하는 사용자에게 incident_alert 자동 생성
사용자 확인 :: "내 유출 여부 확인" 클릭 시 로그인 이메일 해시와 대조
결과 기록 :: exposure_check — AFFECTED / NOT_AFFECTED
```
