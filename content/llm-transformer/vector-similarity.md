  - q: "유클리드 거리와 코사인 유사도는 각각 언제 쓰나?"
    a: "유클리드 거리는 두 점 사이 직선 거리라 벡터의 크기 차이까지 반영한다. 코사인 유사도는 두 벡터 사이 각도만 보므로 길이가 달라도 방향이 같으면 1이 된다. 문서 길이가 제각각인 텍스트에서는 같은 단어를 세 번씩 반복한 문서도 같은 내용으로 봐야 하므로 코사인 유사도가 더 적합하다."

```formula
d(x, y) = √( Σ (xᵢ − yᵢ)² ) :: 유클리드 거리, 각 차원 차이 제곱합의 제곱근
a · b = Σ aᵢbᵢ = ‖a‖ ‖b‖ cos θ :: 내적, 정사영 길이 × 길이 (크기와 방향 모두 반영)
cos θ = (A · B) ÷ (‖A‖ ‖B‖) :: 코사인 유사도, 내적을 길이로 정규화 (L2 Normalization)
softmax(zᵢ) = e^zᵢ ÷ Σⱼ e^zⱼ :: 점수를 합이 1인 확률로
```

문서1 (강아지 고양이) = (1, 1, 0) 과 누가 더 비슷한가? (슬라이드 Case Study)

| 비교 대상 | 유클리드 거리 | 코사인 유사도 |
|---|---|---|
| 문서2 (강아지 고양이 토끼) = (1, 1, 1) | **1.00** (더 가까움) | 0.82 |
| 문서3 (강아지×3 고양이×3) = (3, 3, 0) | 2.83 | **1.00** (같은 방향) |

> [!tip] 행렬곱이 곧 학습
> X(8×10) × W(10×5) = Y(8×5): 8개 단어의 10차원 벡터를 5차원으로 선형변환. 딥러닝 학습은 W를 조금씩 고쳐 단어 벡터를 "의미 있는 위치"로 재배치하는 과정. 단어가 바뀌는 게 아니라 단어를 표현하는 벡터가 바뀜.
