qa:
  - q: 내부 검증 점수와 실제 제출 점수가 다르면 어떻게 해석하나요?
    a: "2차에서 OOF 0.8025인데 실제 점수가 0.835로 0.033 높게 나왔고, 처음엔 제출 모델이 100% 데이터로 학습해서라고 해석해 폴드를 10겹으로 늘렸습니다. 하지만 이것은 검증되지 않은 가설이고, 평가 집합의 차이나 927개라는 작은 표본의 변동도 원인일 수 있다고 기록을 정정했습니다. 내부 점수는 방향을 고르는 데 쓰고, 성능 주장에는 실제 제출 점수를 따로 적었습니다."
  - q: round 8이 round 7보다 좋아졌다고 말할 수 있나요?
    a: "증거가 약하다고 판단했습니다. 같은 재현율에서 두 회차의 정밀도가 거의 겹치고 최고 OOF F1 차이도 0.0015뿐이며, 실제 제출에서 바뀐 예측은 927개 중 21개였습니다. 역산하면 맞힌 개수가 11개 정도 늘었는데 19번 중 11번 이상을 운으로 맞힐 확률이 32%이고, 고정 예측의 bootstrap 95% 구간도 0을 포함했습니다. 그래서 '개선'이 아니라 '측정 오차 범위 안의 변화'로 보고했습니다."
  - q: 대회 규정과 재현성은 어떻게 관리했나요?
    a: "외부 유사 데이터, 외부 독성 라벨, 외부 사전학습 가중치는 최종 학습·예측·보정에 쓰지 않았고, 검토용 외부 자료는 격리 폴더로 옮겨 선택 코드에서 차단했습니다. 회차별 제출물과 설정(info.json), 블렌드 재료 확률, 데이터 SHA-256, 실행 환경을 아카이브에 남겨 모델을 다시 학습하지 않고도 최종 가중치와 임계값 선택을 재현할 수 있게 했습니다."
