  - RMSE는 잔차의 전형적인 크기, 타깃과 같은 단위라 해석이 쉬움 (회귀선 ±2·RMSE에 약 95%)
  - R² = SSR / SST = 1 − SSE / SST, 종속변수 변동 중 모형이 설명한 비율

qa:
  - q: R²와 Adjusted R²의 차이는?
    a: "R²는 종속변수의 전체 변동 중 회귀모형이 설명하는 비율로 0~1 사이입니다. 그런데 변수를 추가하면 쓸모없는 변수라도 R²가 항상 늘어나므로, 다중회귀에서는 변수 개수를 보정한 Adjusted R²로 모델을 비교합니다."
  - q: 회귀분석 결과표에서 무엇을 확인하나요?
    a: "F-test의 유의한 F로 모델 전체가 의미 있는지, 계수별 p-value로 어떤 변수가 실제로 영향을 주는지, 계수의 부호와 크기로 영향의 방향과 크기, R²·Adjusted R²로 설명력, 표준오차(RMSE)로 평균적인 예측 오차를 봅니다. 실습에서는 판매가격의 p가 0.813이라 제거하고 쿠폰 수만으로 재적합했습니다."
  - q: RMSE는 왜 MSE에 루트를 씌우나요?
    a: "MSE는 오차를 제곱해서 단위가 타깃의 제곱이 됩니다. 루트를 씌우면 타깃과 같은 단위가 되어 '평균적으로 약 27명 틀린다'처럼 바로 해석할 수 있습니다. 추정의 표준오차, 회귀의 표준오차라고도 부릅니다."

```formula
RMSE = √( (1/n) Σ(ŷᵢ − yᵢ)² ) :: 잔차(실제값 − 예측값)의 전형적인 크기
SST = SSR + SSE :: 총변동 = 설명 가능한 변동(회귀) + 설명 불가능한 변동(잔차)
R² = SSR / SST = 1 − SSE / SST :: 설명력, R² 0.6이면 Y 분산의 60%를 설명
```

| 결과표 항목 | 실습 값 (구매고객수 ~ 쿠폰수 + 판매가격) | 해석 |
| --- | --- | --- |
| 회귀식 | y = 0.109·x₁ + 0.003·x₂ + 274.375 | 쿠폰 1장당 고객 0.109명 |
| 결정계수 / 조정된 결정계수 | 0.773 / 0.735 | 전체 변동의 약 73.5% 설명 |
| 표준 오차 (RMSE) | 27.565 | 예측이 평균 ±27.6명 틀림 |
| 유의한 F | 0.000 | 모형 전체는 유의 |
| 계수 p-값 | 쿠폰 3.8E-05, 가격 0.813 | 가격은 유의하지 않음 → 제거 |
| 재적합 | y = 0.108·x₁ + 282.892, Adj R² 0.730 | 쿠폰 10장 추가 시 약 1.08명 증가, 3,000장이면 약 607명 |
