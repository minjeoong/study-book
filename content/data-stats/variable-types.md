keypoints:
  - 척도는 명목 < 서열 < 구간 < 비율 순으로 정보량이 늘어남
  - 형태는 범주형 vs 수치형(이산·연속), 역할은 종속·독립·통제변수
  - 같은 변수도 세 관점으로 동시에 설명되며, 이것이 기법 선택의 출발점
qa:
  - q: 명목·서열·구간·비율 척도를 설명해 보세요.
    a: "명목은 구분만 가능(성별, 혈액형), 서열은 순서까지(고객등급, 만족도 1~5점), 구간은 간격이 같지만 절대 0이 없음(섭씨온도, IQ), 비율은 절대 0이 있어 두 배·절반 비교까지 가능(매출, 키)합니다. 위로 갈수록 정보량이 늘고, 평균·표준편차는 구간척도부터 의미가 있습니다."
  - q: 통제변수는 왜 필요한가요?
    a: "공부시간과 시험점수의 관계를 볼 때 수면시간이나 IQ도 점수에 영향을 줍니다. 이런 변수를 일정하게 두거나 함께 고려해야 독립변수의 순수한 효과를 공정하게 비교할 수 있습니다."
  - q: 데이터 유형에 따라 통계 기법은 어떻게 달라지나요?
    a: "범주형 vs 연속형이면 t-test(성별에 따른 급여 차이), 연속형 vs 연속형이면 상관·회귀분석(광고비와 매출), 범주형 vs 범주형이면 카이제곱 검정(혈액형과 질병)을 씁니다. 그래서 분석 전에 변수 유형부터 확인합니다."

```layers
명목척도 (Nominal) :: 구분만 가능 · 성별, 혈액형, 지역 · 빈도, 최빈값
서열척도 (Ordinal) :: + 순서 · 고객등급, 만족도 1~5점 · 중앙값, 순위
구간척도 (Interval) :: + 간격 동일, 절대 0 없음 · 섭씨온도, IQ · 평균, 분산
비율척도 (Ratio) :: + 절대 0, 비율 비교 · 매출, 키, 나이 · 모든 사칙연산
```

| 관점 | 분류 | 예시 |
| --- | --- | --- |
| 척도 (어떻게 비교?) | 명목 · 서열 · 구간 · 비율 | 위 표 |
| 형태 (어떻게 처리?) | 범주형 / 수치형(이산 · 연속) | 혈액형 / 불량개수 · 키 |
| 역할 (무엇을 설명?) | 종속(Y) · 독립(X) · 통제 | 매출 · 광고비 · 지역, 매장 규모 |

- 성별의 평균 1.6은 의미 없음, 고객등급 A·B·C 평균은 계산은 되지만 등급 간 간격이 같지 않음
- 범주형 요약은 `value_counts(normalize=True)`(비율), `groupby("category")["sales"].mean()`(그룹 통계)

> [!tip] 면접 팁
> "광고가 매출에 미치는 영향" 하나로 설명: 광고비는 비율척도·수치형·독립변수, 지역은 명목척도·범주형·통제변수.
