```formula
f(x) = 1 / (σ√(2π)) · e^(−(x − μ)² / 2σ²) :: 정규분포 N(μ, σ²)의 확률밀도
z = (x − μ) / σ :: 표준화, N(0, 1)로 변환
P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx :: 연속형은 구간 면적이 확률
E[X] = Σ xᵢ · P(xᵢ) :: 기대값, 분포의 무게중심 (동전 6번 앞면 기대값 0.5 × 6 = 3)
```

```layers
확률변수 :: 실험 결과를 숫자로 대응 (몸무게, 앞면 개수), 분포를 가짐
이산형 · PMF :: 셀 수 있는 값, f(x) = P(X = x)
연속형 · PDF :: 실수 구간, 한 점 확률 0, 면적이 확률
정규분포 :: 봉우리 하나, 종 모양, 좌우대칭, 전체 면적 1
표준정규분포 :: μ = 0, σ = 1, 표준정규분포표로 누적확률 (P(Z ≤ 1.23) = 0.8907)
```

- 히스토그램은 도수분포표(구간 수 결정 → 구간 폭 → 도수 기입)를 막대로 그린 것, 정규분포는 "이상적인 히스토그램"
- 음수 z는 대칭을 이용해 1 − P(Z ≤ |z|)로 계산
- 정규성 확인은 히스토그램 + Q-Q plot + 검정(`scipy.stats.normaltest`, H₀ = 정규분포를 따른다)을 함께 봄

> [!tip] 면접 팁
> "80점이 몇 등쯤인가"는 z로 바꾸면 바로 답이 나온다. 수학 z = 0.5 (상위 약 31%), 영어 z = 1.25 (상위 약 11%).
