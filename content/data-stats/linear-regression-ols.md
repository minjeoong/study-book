qa:
  - q: 최소제곱법에서 왜 잔차를 제곱하나요?
    a: "그냥 더하면 양수와 음수 잔차가 서로 상쇄되기 때문입니다. 제곱하면 큰 오차에 더 큰 벌점을 주고(오차 2는 4, 5는 25), 미분이 쉬우며, 제곱함수가 U자 모양이라 항상 하나의 최솟값(해)을 가집니다."
  - q: 회귀계수와 상관계수는 어떤 관계인가요?
    a: "기울기는 b = r × SDy / SDx입니다. 키가 평균보다 1 표준편차(8.5cm) 큰 사람의 몸무게는 평균에 1 표준편차(11.9kg)를 더한 75.4kg이 아니라, 상관계수 0.67을 곱한 약 8kg만 더한 71.5kg으로 예측합니다. r = 1일 때만 1 SD만큼 따라갑니다."
  - q: 평균으로의 회귀(회귀효과)란?
    a: "극단적인 관측값은 다음 측정에서 평균 쪽으로 가까워지는 경향입니다. 중간고사를 평소보다 잘 본 학생은 운이나 일시적 요인이 섞였을 가능성이 커서 기말고사 예측 점수는 평균 쪽으로 당겨지며, 상관계수가 0에 가까울수록 이 효과가 커집니다."

```flow
Naive 예측 :: 정보가 없으면 모든 사람의 몸무게를 평균 63.5kg으로
조건부 평균 :: 키 176cm 세로띠 안의 몸무게 평균을 예측값으로
회귀직선 :: 키별 평균 몸무게 점들을 하나의 직선으로 근사
최소제곱법 :: 잔차 제곱합이 최소인 기울기·절편 선택
```

```formula
yᵢ = β₀ + β₁xᵢ + εᵢ :: 단순선형회귀 모형, εᵢ는 오차
min Σ(yᵢ − β₀ − β₁xᵢ)² :: 목적함수, 잔차 제곱합 최소화
β̂₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² = Cov(X, Y) / Var(X) :: OLS 기울기
β̂₀ = ȳ − β̂₁x̄ :: 회귀직선은 항상 평균점 (x̄, ȳ)를 지남
b = r · SDy / SDx :: x가 1 SD 늘면 y는 r SD만큼 이동
```

| 후보 직선 | A(1,1) · B(2,2) · C(3,3) 잔차² 합 |
| --- | --- |
| y = 2x | (1−2)² + (2−4)² + (3−6)² = 14 |
| y = x + 2 | (1−3)² + (2−4)² + (3−5)² = 12 |
| y = x | 0 → 최소제곱 직선 |

> [!warn] 헷갈리기 쉬움
> 회귀직선은 "평균의 그래프"를 직선으로 근사한 것이다. 평균들이 곡선을 그리면 직선 근사가 부적절할 수 있다 (선형성 가정).
