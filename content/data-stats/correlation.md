qa:
  - q: 공분산과 상관계수의 차이는?
    a: "둘 다 편차의 곱으로 두 변수가 같이 움직이는 정도를 봅니다. 공분산은 단위에 따라 값의 크기가 달라져 비교가 어렵고, 상관계수는 공분산을 x, y의 표준편차로 나눠 단위가 없고 −1~1로 한정되므로 서로 다른 변수 쌍도 비교할 수 있습니다."

  - q: 표본분산에서 n이 아니라 n − 1로 나누는 이유는?

```formula
Cov(X, Y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1) :: 공분산, 편차 곱의 부호가 방향, 크기가 강도
r = Cov(X, Y) / (sₓ · sᵧ) :: 표준편차로 나눠 단위 제거, −1 ≤ r ≤ 1
df = n − 1 :: 자유도, 평균이 정해지면 마지막 값은 자동으로 결정
```

```compare
양의 상관 (r > 0) | 음의 상관 (r < 0) | r ≈ 0
의미 | 하나가 늘면 다른 것도 증가 | 하나가 늘면 다른 것은 감소 | 선형 관계 거의 없음
편차 곱 | x, y 모두 평균보다 크거나 작음 | 한쪽만 평균보다 큼 | 부호가 섞여 상쇄
실습 예 | 높이 X5 vs 난방부하 Y1 (0.889) | 지붕면적 X4 vs Y1 (−0.862) | 방향 X6 vs Y1 (−0.003)
```

```python
df.corr()                                   # Pearson 상관행렬
sns.heatmap(df.corr(), annot=True, cmap="coolwarm")
df.corr()["Y1"].sort_values(key=abs, ascending=False)   # 타깃과 관계 순위
corr, p = pearsonr(df["X5"], df["Y1"])     # 상관계수 + 유의성(p-value)
```
