qa:
  - q: 선형회귀의 기본 가정을 말해 보세요.
    a: "선형성(X와 Y의 평균적 관계가 직선), 독립성(오차끼리 서로 영향이 없음), 등분산성(예측값과 관계없이 잔차의 퍼짐이 일정), 정규성(잔차가 평균 0인 정규분포), 그리고 다중회귀에서는 독립변수 간 다중공선성이 없어야 합니다. 대부분 잔차 플롯과 Q-Q plot으로 확인합니다."
  - q: 다중공선성이 왜 문제이고 어떻게 확인하나요?
    a: "독립변수들이 거의 같은 정보를 가지면 각 변수의 고유한 영향을 구분할 수 없어 회귀계수가 불안정해지고, 중요한 변수가 유의하지 않은 것처럼 나올 수 있습니다. VIF로 확인하며, 실습에서는 표면적 X2·벽면적 X3·지붕면적 X4의 VIF가 무한대로 나와 서로 완전히 겹치는 정보임을 확인했습니다."
  - q: 정규성 가정은 데이터 자체가 정규분포여야 한다는 뜻인가요?
    a: "아닙니다. 대표적인 오해로, 정규성은 오차(잔차)가 평균 0인 정규분포를 따른다는 가정입니다. 회귀계수는 정규성 없이도 계산되지만 t-test, F-test, p-value, 신뢰구간 같은 추론에 필요하고, 데이터가 충분히 많으면 중심극한정리 덕분에 위반이 큰 문제가 되지 않는 경우가 많습니다."

| 가정 | 잔차에서 확인할 것 | 위배되면 나타나는 현상 |
| --- | --- | --- |
| 선형성 | 특정 패턴 없이 랜덤 | 잔차가 U자·S자 곡선 패턴 |
| 독립성 | 잔차끼리 상관 없음 (자기상관 없음) | 시간·순서에 따라 연속 패턴 (시계열, 공간, 반복측정) |
| 등분산성 | 예측값 전체에서 퍼짐 일정 | 깔때기 모양 (이분산성) → 표준오차·p-value 왜곡 |
| 정규성 | 잔차가 정규분포 | 히스토그램·Q-Q plot이 직선에서 벗어남 (꼬리 두꺼움) |
| 다중공선성 없음 | 독립변수 간 상관 낮음 (VIF) | 계수 불안정, 중요한 변수가 비유의로 나옴 |

```formula
Yᵢ = β₁ + β₂Xᵢ + eᵢ :: 회귀모형
E(eᵢ) = 0 :: 오차의 기대값은 0, 많고 적음이 상쇄
Var(eᵢ) = E(eᵢ²) = σ² :: 등분산, X 값과 무관하게 오차 분포가 같음
Cov(eᵢ, eⱼ) = 0  (i ≠ j) :: 독립성, 자기상관(Serial Correlation) 없음
E(β̂) = β :: 불편 추정량, 추정량의 기대값이 원래 모수
VIFⱼ = 1 / (1 − Rⱼ²) :: Xⱼ를 나머지 X로 회귀한 R², 10 이상이면 다중공선성 의심
```

- 실습 VIF (`variance_inflation_factor`): X2 · X3 · X4 = inf (표면적 = 벽면적 + 2 × 지붕면적), X1 169, X5 134, X6 10.8, X7 · X8 약 4.3~4.5
- 불편 추정량이라도 분산 Var(β̂)이 크면 표본마다 직선이 크게 흔들림 → 추정이 불안정

> [!tip] 면접 팁
> 독립변수와 종속변수의 상관이 높은 것은 좋은 상황, 독립변수끼리 상관이 높은 것이 다중공선성 문제. 강건성(Robustness)은 노이즈·환경 변화에도 성능이 크게 변하지 않는 능력으로, 데이터 품질 향상과 일반화 노력으로 높인다.
