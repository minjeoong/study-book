qa:
  - q: 표준편차와 IQR은 각각 언제 쓰나요?
    a: "표준편차는 모든 값을 쓰는 가장 표준적인 퍼짐 지표지만 평균을 기준으로 하므로 이상치에 민감합니다. IQR은 Q3−Q1로 가운데 50%만 보기 때문에 이상치가 있는 데이터나 치우친 분포를 요약할 때 더 적합하고, 박스플롯의 기준이 됩니다."
  - q: 이상치는 어떻게 탐지하고 처리하나요?
    a: "IQR 방식은 Q1−1.5·IQR, Q3+1.5·IQR 바깥 값을, Z-score 방식은 |z|가 2나 3을 넘는 값을 이상치로 봅니다. 처리는 제거, 상한값으로 치환(capping), 로그 변환, 원인 조사 후 유지가 있으며, 프로모션 같은 실제 이벤트일 수 있으니 도메인 확인이 먼저입니다."
  - q: 변동계수(CV)는 왜 쓰나요?
    a: "평균이 다른 집단의 퍼짐을 공정하게 비교하기 위해서입니다. 공정 A(평균 10, 표준편차 2)와 B(평균 100, 표준편차 5)는 표준편차만 보면 B가 불안정해 보이지만, CV는 A 20%, B 5%로 A가 더 불안정합니다."

```formula
σ² = Σ(xᵢ − μ)² / n :: 분산, 편차 제곱의 평균 (표본분산은 n − 1로 나눔)
σ = √σ² :: 표준편차, 원래 단위로 되돌린 퍼짐. 가장 널리 쓰는 산포 지표
IQR = Q3 − Q1 :: 가운데 50% 데이터의 폭, 이상치에 강건(robust)
하한 = Q1 − 1.5·IQR,  상한 = Q3 + 1.5·IQR :: 박스플롯 수염, 바깥은 이상치
CV = σ / μ × 100% :: 평균 대비 퍼짐, 평균이 0 근처거나 음수면 못 씀
```

- 범위(max − min)는 계산이 쉽지만 이상치에 가장 민감
- 사분위수: n이 홀수면 중앙값을 빼고 양쪽 절반의 중앙값, 짝수면 하위·상위 절반의 중앙값이 Q1·Q3

```python
Q1, Q3 = df["sales"].quantile(0.25), df["sales"].quantile(0.75)
IQR = Q3 - Q1                                    # 140 - 105 = 35
outliers = df[(df["sales"] < Q1 - 1.5*IQR) | (df["sales"] > Q3 + 1.5*IQR)]   # 300 (상한 192.5 초과)

from scipy.stats import zscore
df[zscore(df["sales"]).abs() > 2]                # 300 (z = 2.43)
```

> [!warn] 헷갈리기 쉬움
> Z-score 방식은 이상치가 평균·표준편차 자체를 끌어당겨서 정규분포에 가까울 때만 잘 동작한다. 치우친 데이터면 IQR 방식이 안전.
