qa:
  - q: "의사결정나무는 어떤 기준으로 분할하나요?"
    a: "부모 마디를 자식 마디로 나눌 때 불순도가 가장 많이 낮아지는 변수와 분리값을 고릅니다. 불순도는 지니 지수(임의로 두 개를 뽑았을 때 클래스가 다를 확률)나 엔트로피(정답을 알아내는 데 필요한 평균 질문 수)로 재고, 연속형 타깃이면 분산을 씁니다. 정지규칙을 만족할 때까지 반복한 뒤 오분류 위험이 큰 가지는 가지치기합니다."
  - q: "Feature Importance는 어떻게 계산되고 어떻게 해석해야 하나요?"

```formula
Gini = 1 − Σ pᵢ² :: 0에 가까울수록 순수. 예 (2, 3, 5)/10 → 1 − (0.04 + 0.09 + 0.25) = 0.62
Entropy = − Σ pᵢ log₂ pᵢ :: 같은 예 = 1.485. 한 종류만 있으면 0, 반반이면 1 bit로 최대
감소량 = 분할 전 불순도 − 분할 후 불순도 :: 가장 많이 줄이는 분할을 선택
```

```flow
분리 기준 탐색 :: 연속형은 x < 50 / ≥ 50, 범주형은 {상} / {중, 하}
불순도 비교 :: 분할 후 불순도가 최저인 변수·값 선택
성장 (Growing) :: 각 마디에서 최적 분리 반복
정지규칙 :: 더 나눌 수 없으면 끝 마디
가지치기 (Pruning) :: 부적절한 추론 규칙의 가지 제거
```

| 장점 | 단점 |
| --- | --- |
| if-then 규칙이 그대로 읽혀 비전문가에게 설명 쉬움 | 깊어질수록 과적합 → 가지치기, 최대 깊이 제한 필요 |
| 표준화 불필요, 범주·연속 모두 처리, 이상치·결측에 덜 민감 | 작은 데이터 변화에도 다른 트리 생성 (불안정) → 앙상블로 보완 |
| Feature Importance로 중요 변수 파악 | 단일 트리는 복잡한 상호작용 반영 한계, 클래스 불균형에 취약 |
